# Nexus PC — Roadmap

Порядок следует ТЗ (P0–P11) с обоснованными изменениями, отмеченными **[изм.]**.

| Этап | Содержание | Критерий готовности |
|------|-----------|---------------------|
| **P0** ✅ | Архитектура, безопасность, протокол v1 (схемы + фикстуры), план | Документы утверждены владельцем. |
| **P1a** ✅ | `Nexus.Core` (модели, каталог команд, разрешения, валидатор) + `Nexus.Tests` | Тесты зелёные (можно на Linux). |
| **P1b** ✅ | `Nexus.Agent`: служба, WSS, сопряжение (код/ссылка; QR — в P1c), вход, power control, аудит; `Nexus.DevClient`; CI | Основное проверено на реальном ПК (W1, W5–W10); остальное — docs/TESTING.md. |
| **P1c** ✅ | `Nexus.Tray`: канал со службой, QR-сопряжение, список программ, профили, блокировка, выключение из сеанса пользователя | Проверено на реальном ПК: T1, T3–T8, T10, T11; осталось T2, T9, T12. |
| **P1d** | **[изм.]** Базовые метрики CPU/RAM/диски/сеть через Performance Counters | Нужны Command Center уже на P2; полноценный Monitoring остаётся на P4. |
| **P2** ✅ | iOS: `NexusKit` (сеть с закреплённым сертификатом, вход по подписи), дизайн-система, QR-сопряжение, Command Center, профили, приложения, питание | Проверено на iPhone (iOS 27) и ПК: сопряжение по QR, статус, блокировка, профили, приложения, отложенное выключение и отмена, переподключение. |
| **P2.0** ✅ | **[изм.]** CI GitHub Actions на macOS: `swift test` (NexusKit на общих примерах с C#), XcodeGen + `xcodebuild` без подписи → .ipa; установка через Sideloadly (docs/IOS.md) | Проверено 2026-11-16: собрано в CI без Mac (Xcode 26.6), установлено через Sideloadly с бесплатным Apple ID, открывается на iPhone (iOS 27). |
| **P3** ✅ | Siri/Shortcuts, виджет быстрых действий, Live Activity отсчёта выключения | **[изм.]** Уведомления в фоне (ntfy) перенесены в P4 вместе со Smart Alerts: это работа на стороне ПК. |
| **P4a** ✅ | Мониторинг: CPU, RAM, GPU NVIDIA, диски, сеть, история, экран с графиками | Недоступные датчики честно помечены. |
| **P4b** | Smart Alerts (пороги, повторы), уведомления в фоне через ntfy, «ПК выключился неожиданно» | |
| **P5** | Remote Touchpad, затем спайк WebRTC → Remote Screen | Задержка и качество измерены. |
| **P6** | Automation Studio (движок на ПК), PC History | |
| **P7** | File Transfer, Clipboard Sync | Проверка SHA-256, отмена, докачка. |
| **P8** | Multi-PC UI и переключение | **[изм.]** Модель данных multi-PC закладывается с P1. |
| **P9** | Nexus AI: интерфейс провайдера, разбор по правилам, адаптер Ollama на ПК | AI не может выйти за каталог команд. |
| **P10** | RGB Sync (OpenRGB, Dynamic Lighting) | Поддержка подтверждена на реальном оборудовании. |
| **P11** | Установщик Windows, автообновление, инструкции Tailscale/ntfy/Sideloadly | **[изм.]** Gateway, Relay и TestFlight — только если владелец когда-либо решит платить (D11). |

Удалённый доступ до P11 — через пользовательский VPN (Tailscale/WireGuard): работает без своей инфраструктуры и без открытых портов.
