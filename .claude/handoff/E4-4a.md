# Решения владельца по E4-4 (2026-11-24)

1. Отвязка ПК остаётся локальной. Серверную запись владелец удаляет через управление устройствами аккаунта. Эндпоинт с подписью ключом ПК не добавлять.
2. Ошибки pc-token: `auth.required` и `pc.not_found` — стирать refresh; `bad.request` — НЕ стирать, пока сервер явно не подтвердил необратимую недействительность токена. Тесты на каждое поведение.
3. ACL `account.dat` не менять сейчас. Отдельная задача SEC-ACL (ниже). Текущую защиту не ослаблять.
4. Опрос входа остаётся в трее, фоновую задачу не добавлять. QA проверяет корректность состояния аккаунта и доступности функций.
