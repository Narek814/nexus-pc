# Nexus PC — что сделано

Итоги проекта на 18 ноября 2026 года (работа шла с 14 по 18 ноября).

Nexus PC — приложение для iPhone, которое управляет Windows-компьютером по домашней сети. На ПК работает служба Nexus PC и значок «N» у часов. Всё бесплатно: без платного аккаунта Apple, без облачных серверов и подписок.

Всё перечисленное ниже проверено на вашем ПК и iPhone, если не сказано иначе.

---

## Что умеет

### Питание
- Выключение и перезагрузка с подтверждением и отсчётом Windows; отмена.
- Сон и блокировка экрана.
- **Включение ПК по сети (Wake-on-LAN).** Будит ПК из сна по Wi-Fi.
- Состояние ПК на главном экране: имя, время работы, версия.
- Отсчёт до выключения на экране блокировки и в Dynamic Island (Live Activity).

### Программы и профили
- **Список программ** собирается на ПК: из меню «Пуск», файлы `.exe` и **приложения Microsoft Store**. Телефон запускает только программы из этого списка.
- Закрытие программы с телефона, если разрешено. Приложения Store можно только запускать.
- **Профили** Gaming, Developer, Creator, Night: несколько программ одной кнопкой. Профиль подсветки с тем же именем включается вместе с профилем.

### Siri и виджеты
- Фразы по-английски и по-русски: «Как мой компьютер в Nexus PC», «Выключи компьютер в Nexus PC», «Запусти Gaming в Nexus PC» и другие. Вместо «Nexus PC» можно сказать «Нексус».
- Виджеты быстрых действий на главном экране и экране блокировки.

### Мониторинг
- Загрузка процессора, памяти и видеокарты NVIDIA; температуры видеокарты и процессора; частоты; диски; сеть.
- Графики за 10 минут, 1 час и 24 часа.

### Подсветка
- Цвет, яркость, эффекты и профили подсветки через OpenRGB.
- Проверено: плата ASUS PRIME B660M-A (кулер и вентиляторы на ARGB-разъёмах), мышь Redragon M914 по проводу и по радио.
- OpenRGB 1.1 входит в установщик и запускается службой сам, без окна. Окно для настройки устройств: значок «N» → «Настроить подсветку (OpenRGB)…».

### Тачпад и клавиатура
- Курсор, клик, правый клик, перетаскивание, прокрутка.
- Печать с клавиатуры iPhone, клавиши Esc/Tab/стрелки/Win, сочетания (Ctrl+C/V/Z, Alt+Tab, Alt+F4), громкость и медиа.

### Экран ПК на iPhone
- **Видео H.264** до 30 кадров в секунду, со встроенными кодеками Windows и iPhone. Запасной вариант — кадры JPEG.
- Качество «Быстро / Обычно / Чётко», весь экран с поворотом, приближение до 5×.
- Управление касаниями и ряд кнопок (Esc, Tab, стрелки, Win, Alt+Tab, Ctrl+C/V/Z, Alt+F4, F5, F11).
- Перед первым показом ПК спрашивает разрешение. Остановить показ можно из меню значка «N».

### Файлы и буфер обмена
- Фото, видео и файлы с iPhone на ПК (в папку «Загрузки\Nexus PC») и обратно.
- Прогресс, отмена, проверка целостности (SHA-256), докачка после обрыва.
- Текст в буфер ПК и обратно, только по нажатию.

### Автоматизации и история
- Правила выполняет сам ПК, даже без телефона.
  - **Когда:** по расписанию, по датчику (температура, загрузка), при включении ПК, при входе в Windows.
  - **Что делать:** профиль, программа, подсветка, блокировка, сон, выключение, пауза.
- Шаблоны: «Ночь», «Перегрев видеокарты», «Перегрев процессора», «При входе в Windows».
- **История** по дням: команды с телефона и запуски автоматизаций.

### Установщик для ПК
- Один файл `NexusPC-Setup.exe`, внутри всё: .NET, OpenRGB 1.1, драйвер PawnIO. Отдельно ничего ставить не нужно.
- Установка, обновление поверх старой версии (настройки сохраняются), удаление.
- Проверяет, что домашняя сеть отмечена в Windows как частная.
- Окно «Устройства и разрешения» в меню значка «N».

### Внешний вид
- Неоновая иконка и тёмный дизайн приложения на iPhone.
- Тёмные окна, неоновые кнопки и тёмное меню на ПК.

## Безопасность

- ПК **не открыт в интернет**: порт 47800 открыт только для частной (домашней) сети.
- Соединение шифруется. iPhone проверяет «отпечаток» ПК, ключ телефона хранится в защищённом чипе (Secure Enclave).
- Подключение нового телефона только по QR-коду с подтверждением на ПК и 6-значным кодом проверки.
- **Разрешения для каждого телефона отдельно.** Мышь и клавиатура, показ экрана, файлы, буфер и автоматизации выдаются только на ПК, с правами администратора.
- Нет произвольных команд, PowerShell и запуска любых путей: только действия из белого списка.
- Сервер OpenRGB доступен только внутри ПК (127.0.0.1).
- Сторонние программы в установщике закреплены по контрольной сумме, подпись PawnIO проверяется при сборке.

## Решения по ходу работы

| Что | Решение |
|-----|---------|
| Несколько ПК (P8) | Не делаем — ваше решение |
| AI-помощник (P9) | Не делаем — ваше решение |
| Уведомления через ntfy и предупреждения | Сделаны, потом **убраны** по вашему решению: нужна сторонняя программа, а push Apple требует платного аккаунта |
| Управление вне дома (Tailscale) | Убрано из агента решением владельца: только домашняя сеть |
| Автопродление подписи (SideStore) | Не делаем — ваше решение |
| Постоянный адрес ПК | Закреплён в роутере: 192.168.0.101 |

## Найдено и исправлено на вашем ПК

- **Русская Windows.** Установщик не понимал ответ службы со словом «Состояние» — исправлено.
- **Файлы заняты.** Окно PowerShell с запущенным агентом мешало обновлению — установщик теперь сам закрывает такие процессы.
- **Новый адрес ПК.** Роутер выдал ПК другой адрес, и телефон не находил его. Теперь приложение само ищет ПК в домашней сети, адрес можно обновить по QR-коду, а в роутере адрес закреплён.
- **Задержка видео экрана.** Кодировщик придерживал кадры — включён режим низкой задержки.
- **Подсветка вентиляторов.** OpenRGB не знал число светодиодов на ARGB-разъёмах — настроено.
- **Трей не обновился** после новой версии — добавлена проверка в инструкцию; теперь трей обновляет установщик.

## Как пользоваться дальше

- **Раз в 7 дней** переустанавливайте приложение на iPhone через Sideloadly с тем же Apple ID. Бесплатная подпись Apple действует 7 дней.
- **Обновление ПК:** скачать новый `NexusPC-Setup.exe` (GitHub → Actions → CI → Artifacts) и запустить поверх старого.
- **Armoury Crate** держите закрытым: он перехватывает подсветку.
- Подробная инструкция — [docs/USER_GUIDE.md](USER_GUIDE.md). Все функции и ограничения — [FEATURES.md](../FEATURES.md).

## Ограничения

- Работает только в той же домашней сети, что и ПК.
- Экран — только основной монитор, без звука. Часть игр и защищённое видео Windows не даёт захватывать (будет чёрный экран).
- Тачпад не работает в окнах администратора, на экране UAC и на экране блокировки (ограничение Windows).
- ПК включается по сети только из сна, не из полного выключения по Wi-Fi.
- Установщик не подписан (подпись платная), поэтому Windows SmartScreen предупреждает при запуске.
- Подсветку монитора Skydimo OpenRGB не поддерживает.

## Цифры

- Около 80 изменений (коммитов) в репозитории Narek814/nexus-pc.
- 475 автоматических тестов на C#, плюс тесты на Swift. Каждое изменение проверяется на Linux и Windows в GitHub Actions; там же установщик ставится, обновляется и удаляется на чистой Windows.
- Составные части: служба Windows (C#/.NET 10), приложение в трее, установщик, приложение для iPhone (SwiftUI) с виджетами и Siri.
