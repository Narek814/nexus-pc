# Nexus PC — включение ПК и доступ вне дома

Всё бесплатно. Удалённого доступа нет: Nexus PC работает только в домашней сети (решение владельца, Guideline 4.2.7). Здесь — **включение ПК** (Wake-on-LAN).

## Включение ПК: Wake-on-LAN

Кнопка «Включить ПК» (видна, когда ПК не в сети) и Siri “Turn on my PC with Nexus PC” отправляют «волшебный пакет» на адрес ПК и во всю домашнюю сеть.

**Ограничения (важно):**
- Работает, только когда **iPhone в той же домашней сети**. Из интернета выключенный ПК так не разбудить — для этого нужно ещё одно всегда включённое устройство дома (роутер с функцией WoL, плата ESP32 ~5 $, Raspberry Pi).
- Почти всегда нужен **кабель Ethernet**: по Wi-Fi выключенный ПК пакет не слышит. Из **сна** некоторые Wi-Fi-адаптеры просыпаются.
- iOS без платного разрешения Apple может не пропускать широковещательный пакет; прямые пакеты на адрес ПК всё равно отправляются. Они надёжнее, пока роутер помнит ПК (обычно минуты–часы после выключения), и из сна.

**Настройка ПК (один раз):**
1. **BIOS/UEFI:** включите *Wake on LAN* / *Power On By PCI-E* / *Resume by PCI-E Device* (название зависит от платы). *ErP/EuP* — выключить.
2. **Диспетчер устройств → Сетевые адаптеры → ваш адаптер → Свойства:**
   - «Дополнительно»: *Wake on Magic Packet* — Enabled; *Shutdown Wake-On-Lan* (если есть) — Enabled.
   - «Управление электропитанием»: отметьте «Разрешить этому устройству выводить компьютер из ждущего режима» и «Разрешать вывод… только с помощью магического пакета».
3. **Быстрый запуск выключить** (он мешает WoL): Панель управления → Электропитание → «Действия кнопок питания» → «Изменение недоступных сейчас параметров» → снять «Включить быстрый запуск».
4. Откройте Nexus PC, пока ПК включён: приложение запомнит MAC-адрес и сеть ПК.

**Проверка:** выключите ПК через «Пуск», подождите минуту, в Nexus PC нажмите «Включить ПК».

### Если ПК подключён по Wi-Fi (как у владельца)

Полностью выключенный ПК по Wi-Fi не просыпается. Схема для Wi-Fi: **вместо выключения — сон** (в Nexus PC кнопка «Сон» или Siri “Put my PC to sleep with Nexus PC”), а будить — «Включить ПК».

0. **Главное (проверено на ПК владельца с Intel Wi-Fi 6 AX201):** по умолчанию Windows не разрешала Wi-Fi-адаптеру будить ПК. Проверка и включение (PowerShell от имени администратора):

```powershell
powercfg /devicequery wake_armed
```

```powershell
powercfg /devicequery wake_programmable
```

Если адаптер есть во втором списке, но нет в первом — разрешите (точное имя из списка):

```powershell
powercfg /deviceenablewake "Intel(R) Wi-Fi 6 AX201 160MHz"
```

1. **Диспетчер устройств → Сетевые адаптеры → Wi-Fi-адаптер (Wireless/Wi-Fi) → Свойства:**
   - «Управление электропитанием»: «Разрешить этому устройству выводить компьютер из ждущего режима» и «…только с помощью магического пакета» — отметить. Если вкладки или пунктов нет, адаптер не умеет просыпаться по сети.
   - «Дополнительно»: *Wake on Magic Packet* — Enabled; *Wake on Pattern Match* — Enabled (если есть).
2. Проверка: в Nexus PC — «Сон», подождите 2–3 минуты (чтобы ПК действительно уснул), затем «Включить ПК».

Получится или нет — зависит от модели Wi-Fi-адаптера и режима сна (S3 или «современный» S0). Если не просыпается — надёжно работает только кабель Ethernet.
