# Nexus PC — включение ПК и доступ вне дома

Всё бесплатно. Два независимых пункта: **доступ вне дома** (Tailscale) и **включение ПК** (Wake-on-LAN).

## 1. Доступ вне дома: Tailscale

Tailscale — бесплатная частная сеть между вашими устройствами (тариф Personal). Порты в роутере открывать **не нужно**, ПК не становится виден из интернета.

1. **ПК:** скачайте Tailscale для Windows с **tailscale.com/download**, установите, войдите (Google/Microsoft/Apple-аккаунт).
2. **iPhone:** установите **Tailscale** из App Store, войдите **тем же** аккаунтом, включите.
3. **ПК, PowerShell от имени администратора** — разрешить Nexus PC только из сети Tailscale (100.64.0.0/10), в любом профиле сети:

```powershell
New-NetFirewallRule -DisplayName "Nexus PC Agent (Tailscale)" -Direction Inbound -Program "C:\Program Files\NexusPC\Agent\Nexus.Agent.exe" -Protocol TCP -LocalPort 47800 -RemoteAddress 100.64.0.0/10 -Profile Any -Action Allow
```

4. **Дома** откройте Nexus PC и потяните экран вниз: приложение узнает новый адрес ПК в Tailscale (`100.x.y.z`) и запомнит его.
5. **Проверка:** выключите Wi-Fi на iPhone (мобильный интернет, Tailscale включён) и откройте Nexus PC — ПК «В сети».

Приложение пробует все известные адреса ПК **одновременно** и берёт первый ответивший: дома — Wi-Fi, вне дома — Tailscale.

## 2. Включение ПК: Wake-on-LAN

Кнопка «Включить ПК» (видна, когда ПК не в сети) и Siri “Turn on my PC with Nexus PC” отправляют «волшебный пакет» на адрес ПК и во всю домашнюю сеть.

**Ограничения (важно):**
- Работает, только когда **iPhone в той же домашней сети**. Выключенный ПК не в Tailscale, поэтому из интернета его так не разбудить — для этого нужно ещё одно всегда включённое устройство дома (роутер с функцией WoL, плата ESP32 ~5 $, Raspberry Pi).
- Почти всегда нужен **кабель Ethernet**: по Wi-Fi выключенный ПК пакет не слышит. Из **сна** некоторые Wi-Fi-адаптеры просыпаются.
- iOS без платного разрешения Apple может не пропускать широковещательный пакет; прямые пакеты на адрес ПК всё равно отправляются. Они надёжнее, пока роутер помнит ПК (обычно минуты–часы после выключения), и из сна.

**Настройка ПК (один раз):**
1. **BIOS/UEFI:** включите *Wake on LAN* / *Power On By PCI-E* / *Resume by PCI-E Device* (название зависит от платы). *ErP/EuP* — выключить.
2. **Диспетчер устройств → Сетевые адаптеры → ваш адаптер → Свойства:**
   - «Дополнительно»: *Wake on Magic Packet* — Enabled; *Shutdown Wake-On-Lan* (если есть) — Enabled.
   - «Управление электропитанием»: отметьте «Разрешить этому устройству выводить компьютер из ждущего режима» и «Разрешать вывод… только с помощью магического пакета».
3. **Быстрый запуск выключить** (он мешает WoL): Панель управления → Электропитание → «Действия кнопок питания» → «Изменение недоступных сейчас параметров» → снять «Включить быстрый запуск».
4. Откройте Nexus PC, пока ПК включён: приложение запомнит MAC-адрес и сеть ПК.

**Проверка:** выключите ПК через «Пуск», подождите минуту, в Nexus PC нажмите «Включить ПК».
