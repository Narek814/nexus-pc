# Дизайн Nexus PC — спецификации

Статус: E5 (дизайн), документы без кода. Реализация — этап E6 (iOS) и задания трея (Windows) по блокам «ЗАДАНИЕ», которые соберёт `code-architect` в E5-5.

## Документы

| Файл | Что внутри | Задание |
|------|-----------|---------|
| `README.md` | этот список, общие правила, заглушки | E5-1 |
| `foundations.md` | дизайн-система: токены цвета, типографика, отступы, радиусы, свечение, анимации; компоненты и их состояния; доступность; правила текстов EN/RU | E5-1 |
| `navigation.md` | информационная архитектура iOS: 5 вкладок, карта экранов ↔ существующие `ios/NexusPC/Views/*.swift`, первый запуск | E5-1 |
| `ios-screens.md`, `error-texts.md` | экраны вкладок, Free/Pro, коды ошибок → тексты | E5-2 |
| `ios-account.md` | аккаунт, вход ПК, устройства, удаление, каркас Pro | E5-3 |
| `windows.md` | трей, окна, установщик | E5-4 |

## Источники решений

- `docs/COMMERCIAL_PLAN.md`, раздел 0 — главнее раздела 5. Аккаунт обязателен: **кнопки «Пропустить» в первом запуске нет**. Free после настройки работает без интернета и без сервера.
- `docs/COMMERCIAL_PLAN.md`, раздел 5 — 5 вкладок, 14 разделов без дубликатов.
- `ARCHITECTURE.md`, раздел 7 — исходные токены и компоненты.
- Apple Human Interface Guidelines: Tab bars, Typography (Dynamic Type), Accessibility, Color, Motion — https://developer.apple.com/design/human-interface-guidelines/
- WCAG 2.2, критерии 1.4.3 (контраст 4.5:1, крупный текст 3:1) и 1.4.11 (нетекстовый контраст 3:1) — https://www.w3.org/TR/WCAG22/
- App Review Guidelines 2.3.1 (нет скрытых функций), 5.1.1(v) (удаление аккаунта) — https://developer.apple.com/app-store/review/guidelines/

## Заглушки (не заменять конкретикой до решения владельца)

| Заглушка | Что означает |
|----------|--------------|
| `{DOWNLOAD_URL}` | страница загрузки Nexus PC для Windows |
| `{ACCOUNT_URL}` | страница управления аккаунтом на сайте |
| `{SUPPORT_URL}` | страница поддержки |
| `{PRICE_MONTHLY}`, `{PRICE_YEARLY}`, `{TRIAL}` | цены и пробный период (E7) |
| `{LIMIT}` | серверный лимит (файлы Free, число ПК) — в UI числа не пишем, подставляет сервер или формулировка без числа |

В документах дизайна не указываются цены, домен, названия поставщиков сервера и оплаты.

## Общие правила

- Только существующие функции продукта и одобренного плана. Новые экраны — только по решению владельца.
- Developer-инструменты — только в Debug-сборке (`#if DEBUG`). В релизе — открытый раздел «Диагностика» в Help (App Review 2.3.1).
- Тексты интерфейса передаются таблицей «ключ · en · ru · где»; в `.xcstrings` и `.resx` их вносит исполнитель.
