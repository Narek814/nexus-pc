# Nexus PC для iPhone — сборка без Mac и установка

Решение D12 (ARCHITECTURE.md): Mac не нужен, всё бесплатно.

```
GitHub Actions (macOS)          ваш ПК с Windows               iPhone
─────────────────────           ────────────────               ──────
swift test (NexusKit)     →     скачать NexusPC-unsigned.ipa →  установить через
xcodegen + xcodebuild           Sideloadly + бесплатный         кабель USB
→ NexusPC-unsigned.ipa          Apple ID подписывает
```

**Статус (P2.0):** приложение — заготовка Command Center в стиле Nexus PC. Умеет проверить ссылку сопряжения (вставить из буфера). Подключения к ПК пока **нет** — это этап P2.

## 1. Скачать сборку

1. На GitHub откройте репозиторий → вкладка **Actions** → слева **iOS**.
2. Откройте последний запуск с зелёной галочкой.
3. Внизу, в разделе **Artifacts**, скачайте **NexusPC-unsigned-ipa** (zip) и распакуйте: внутри `NexusPC-unsigned.ipa`.

Сборка хранится 14 дней. Новую можно запустить кнопкой **Run workflow** на той же странице.

## 2. Установить Sideloadly (один раз)

- Скачивайте только с официального сайта **sideloadly.io**. Он бесплатный.
- Выполните требования с этого сайта для Windows (драйверы Apple для подключения iPhone по кабелю).

Sideloadly подписывает приложение вашим Apple ID и ставит его на iPhone. Пароль Apple ID вводится в Sideloadly; если не хотите вводить основной, заведите отдельный бесплатный Apple ID — для установки этого достаточно.

## 3. Установить на iPhone

1. Подключите iPhone к ПК кабелем, разблокируйте, нажмите «Доверять этому компьютеру».
2. В Sideloadly перетащите `NexusPC-unsigned.ipa` в окно, выберите iPhone, введите Apple ID, нажмите **Start**.
3. На iPhone (iOS 16+): **Настройки → Конфиденциальность и безопасность → Режим разработчика → Вкл.** (iPhone перезагрузится). Этот пункт появляется после первой попытки установки.
4. **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
5. Откройте **Nexus PC** на экране «Домой».

## Ограничения бесплатного Apple ID

- Приложение работает **7 дней**, затем его нужно установить заново (шаг 3, пункты 1–2).
- Не больше 3 своих приложений на устройстве и 10 App ID в неделю (виджеты позже займут свои App ID).
- Нет push-уведомлений Apple и App Groups (см. FEATURES.md, обходы D11).

## Как это проверяется

- `swift test` для NexusKit прогоняет **те же** контрольные примеры, что C#-тесты: `shared/protocol/fixtures/crypto.v1.json` (код проверки, строка для подписи, формат подписи DER) и `pairing-links.v1.json`. Расхождение Swift и C# — красный CI.
- Xcode-проект не хранится в репозитории: его генерирует XcodeGen из `ios/project.yml` (только в CI).
