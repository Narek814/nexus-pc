# Nexus PC — Функции и статус

Легенда: ⬜ не начато · 🟨 в работе · 🟦 заглушка/прототип · ✅ готово и проверено на реальном устройстве

Реализована основа: протокол, служба агента, сопряжение, вход и команды питания (🟨 — работает в тестах, ждёт проверки на реальном ПК). Статус ✅ ставится только после проверки на реальном iPhone и Windows-ПК.

| Модуль | Функция | Этап | Статус | Ограничения платформы |
|--------|---------|------|--------|-----------------------|
| Core | Протокол v1: схема, разбор запросов, белый список команд, разрешения, защита от повторов, подтверждение critical | P0/P1a | 🟨 | Реализовано, используется агентом, покрыто тестами. |
| Agent | Служба Windows, WSS с pinning, сопряжение (код + подтверждение на ПК), вход по подписи, отзыв устройств, разрешения, аудит | P1b | 🟨 | Служба, сопряжение и вход проверены на реальном ПК; остальное — docs/TESTING.md. |
| Power | Wake-on-LAN | P1 | ⬜ | Бесплатно (D11): WoL роутера или unicast-пакет на IP — ненадёжно после полного выключения. |
| Power | Выключение / перезагрузка / сон / отмена | P1b | 🟨 | Отложенное выключение и отмена проверены на реальном ПК; сон и перезагрузка — ещё нет. |
| Power | Блокировка Windows | P1c | 🟨 | Через Nexus.Tray; проверено тестами, на реальном ПК — нет. |
| Power | Текущее состояние ПК (`pc.status`) | P1b | 🟨 | Имя, ОС, время работы, версия. «Выключен» и «нет связи» неразличимы без постоянного наблюдателя. |
| Apps | Список программ (ярлыки «Пуск», .exe), запуск, мягкое закрытие разрешённых | P1c | 🟨 | Через Nexus.Tray от имени пользователя; пути не уходят с ПК. Программы Store — позже. На реальном ПК не проверено. |
| Profiles | Профили (Gaming/Developer/Creator/Night), правка на ПК и с телефона, запуск | P1c | 🟨 | Только программы из списка ПК. На реальном ПК не проверено. |
| Pairing | Окно сопряжения в трее: QR, копирование ссылки, подтверждение | P1c | 🟨 | QR проверен независимым декодером (40 версий); сканировать пока нечем — iPhone-приложение на P2. |
| Command Center | Главный экран: состояние ПК, питание, блокировка, профили, приложения | P2 | ✅ | Проверено на реальном iPhone и ПК (docs/TESTING.md I1–I8). |
| iOS Pairing | Сопряжение по QR (камера), код проверки, ключ в Secure Enclave, Keychain | P2 | ✅ | Проверено на реальном iPhone. |
| Design System | Токены, GlassCard, NeonButton, PowerTile, StatusPill | P2 | 🟨 | Учитывает Reduce Transparency / Reduce Motion. |
| Siri | App Intents: статус, блокировка, сон, выключение/перезагрузка с подтверждением и отсчётом, отмена, профили, программы | P3 | ✅ | Английские фразы (язык iPhone); русские — позже через AppShortcuts.xcstrings. Включение ПК — с Wake-on-LAN. |
| Widgets | Быстрые действия (блокировка, Gaming, выключение), значок экрана блокировки | P3 | ✅ | Без App Groups у виджета нет ключа: кнопки открывают приложение. Статус ПК в виджете — только с платным аккаунтом. |
| Live Activities | Отсчёт до выключения/перезагрузки (экран блокировки, Dynamic Island) | P3 | ✅ | Таймер рисует система, обновления не нужны. Передача файлов — P7. |
| Notifications | «ПК включился / выключается / выключен неожиданно», предупреждения; в фоне через ntfy | P4b | ✅ | Нужно приложение ntfy (бесплатно); выключено по умолчанию. |
| Monitoring | Загрузка CPU, RAM, GPU NVIDIA (загрузка, температура, VRAM, частоты), диски, сеть; графики 10 мин/1 ч/24 ч; выбор показателей и интервала | P4a | ✅ | Температура и частота CPU — недоступны без драйвера датчиков (LHM — решение владельца). AMD/Intel GPU — позже. История — до перезапуска службы. |
| Smart Alerts | Перегрев GPU, долгая загрузка CPU/RAM, мало места на диске; выдержка, гистерезис, без повторов; пороги в приложении | P4b | ✅ | Температура CPU — нет датчика (решение владельца). |
| Touchpad | Курсор, клики, прокрутка, жесты, клавиатура, медиа, громкость | P5 | ⬜ | Не работает на защищённом рабочем столе (UAC). |
| Remote Screen | WebRTC-трансляция и управление | P5 | ⬜ | Требует спайка по выбору WebRTC-стека. |
| Automation | Триггер → Условие → Действие | P6 | ⬜ | Выполняется на ПК. |
| History | Сеансы, команды, события, телеметрия, хранение | P6 | ⬜ | |
| File Transfer | Отправка/получение, прогресс, отмена, SHA-256, папки | P7 | ⬜ | Фоновые загрузки iOS — background URLSession. |
| Clipboard | Ручная отправка/получение текста | P7 | ⬜ | Только по явному действию. |
| Multi-PC | Несколько ПК, переключение | P8 | ⬜ | Модель данных — с P1. |
| Nexus AI | План → подтверждение → выполнение | P9 | ⬜ | Ollama на ПК (нужна видеокарта) + правила. |
| RGB | Цвет, яркость, эффекты, профили | P10 | ⬜ | Поддержка только проверенного оборудования (OpenRGB / Dynamic Lighting). |
