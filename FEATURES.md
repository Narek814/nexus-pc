# Nexus PC — Функции и статус

Легенда: ⬜ не начато · 🟨 в работе · 🟦 заглушка/прототип · ✅ готово и проверено на реальном устройстве

Статус ✅ ставится только после проверки на реальном iPhone и Windows-ПК владельца; 🟨 — написано и проверено тестами, на реальных устройствах ещё не подтверждено. Подробности проверок — docs/TESTING.md. Инструкция пользователя — docs/USER_GUIDE.md.

| Модуль | Функция | Этап | Статус | Ограничения платформы |
|--------|---------|------|--------|-----------------------|
| Core | Протокол v1: схема, разбор запросов, белый список команд, разрешения, защита от повторов, подтверждение critical | P0/P1a | ✅ | Используется всеми функциями ниже; общие примеры проверяются и в C#, и в Swift. |
| Agent | Служба Windows, WSS с pinning, сопряжение (код + подтверждение на ПК), вход по подписи, отзыв устройств, разрешения, аудит | P1b | ✅ | Проверено на реальном ПК с iPhone. |
| Power | Wake-on-LAN: кнопка «Включить ПК», Siri “Turn on my PC” | P-Remote | ✅ | Проверено: пробуждение из сна по Wi-Fi (Intel AX201). Из полного выключения по Wi-Fi — нет; только из той же сети. |
| Remote | Доступ вне дома через Tailscale; одновременная попытка всех адресов ПК | P-Remote | 🟦 | Код и инструкция есть; у владельца не заработал, отложен по его решению. |
| Power | Выключение / перезагрузка / сон / отмена | P1b | ✅ | Отложенное выключение, отмена и выключение через Siri проверены на реальном ПК; перезагрузка отдельно не отмечалась. |
| Power | Блокировка Windows | P1c | ✅ | Через Nexus.Tray; проверено на реальном ПК (в т.ч. через Siri). |
| Power | Текущее состояние ПК (`pc.status`) | P1b | 🟨 | Имя, ОС, время работы, версия. «Выключен» и «нет связи» неразличимы без постоянного наблюдателя. |
| Apps | Список программ (ярлыки «Пуск», .exe), запуск, мягкое закрытие разрешённых | P1c | ✅ | Через Nexus.Tray от имени пользователя; пути не уходят с ПК. Запуск проверен на реальном ПК (Steam). Программы Microsoft Store — не поддерживаются. |
| Profiles | Профили (Gaming/Developer/Creator/Night), правка на ПК и с телефона, запуск | P1c | ✅ | Только программы из списка ПК. Проверено на реальном ПК (в т.ч. «Start Gaming» через Siri). |
| Pairing | Окно сопряжения в трее: QR, копирование ссылки, подтверждение | P1c | ✅ | QR проверен независимым декодером (40 версий) и камерой iPhone. |
| Command Center | Главный экран: состояние ПК, питание, блокировка, профили, приложения | P2 | ✅ | Проверено на реальном iPhone и ПК (docs/TESTING.md I1–I8). |
| iOS Pairing | Сопряжение по QR (камера), код проверки, ключ в Secure Enclave, Keychain | P2 | ✅ | Проверено на реальном iPhone. |
| Design System | iPhone: токены, GlassCard, NeonButton, PowerTile, неоновая иконка. ПК: тёмные окна, неоновые кнопки, тёмное меню трея, значок | P2/доводка | 🟨 | Учитывает Reduce Transparency / Reduce Motion. Новая иконка и новый вид окон ПК на устройствах ещё не проверены. |
| Siri | App Intents: статус, блокировка, сон, выключение/перезагрузка с подтверждением и отсчётом, отмена, профили, программы | P3 | ✅ | Английские фразы (язык iPhone); русские — позже через AppShortcuts.xcstrings. Включение ПК — с Wake-on-LAN. |
| Widgets | Быстрые действия (блокировка, Gaming, выключение), значок экрана блокировки | P3 | ✅ | Без App Groups у виджета нет ключа: кнопки открывают приложение. Статус ПК в виджете — только с платным аккаунтом. |
| Live Activities | Отсчёт до выключения/перезагрузки (экран блокировки, Dynamic Island) | P3 | ✅ | Таймер рисует система, обновления не нужны. Передача файлов — P7. |
| Notifications | «ПК включился / выключается / выключен неожиданно», предупреждения; в фоне через ntfy | P4b | ✅ | Нужно приложение ntfy (бесплатно); выключено по умолчанию. |
| Monitoring | Загрузка CPU, RAM, GPU NVIDIA (загрузка, температура, VRAM, частоты), диски, сеть; графики 10 мин/1 ч/24 ч; выбор показателей и интервала | P4a | ✅ | Температура и частота CPU — через LibreHardwareMonitor, нужен драйвер PawnIO (ставится с OpenRGB); на ПК владельца ещё не проверено. AMD/Intel GPU — позже. История — до перезапуска службы. |
| Smart Alerts | Перегрев GPU, долгая загрузка CPU/RAM, мало места на диске; выдержка, гистерезис, без повторов; пороги в приложении | P4b | ✅ | Предупреждения о температуре CPU пока нет (датчик добавлен 2026-11-17). |
| Touchpad | Курсор с ускорением, клик, правый клик двумя пальцами, перетаскивание удержанием, прокрутка двумя пальцами, печать с клавиатуры iPhone, Esc/Tab/стрелки/Win и сочетания (Ctrl+C/V/Z, Alt+Tab, Win+D, Alt+F4), медиа и громкость | P5 | ✅ | Нужно разрешение `input` (выдаёт администратор ПК). Проверено на реальном ПК с iPhone. Не работает в окнах администратора, на экране блокировки и в UAC (ограничение Windows). Без трея недоступен. |
| Remote Screen | Экран основного монитора на iPhone (видео H.264 до 30 к/с встроенными кодеками Windows и iPhone, запасной вариант — кадры JPEG; «Быстро/Обычно/Чётко», к/с и задержка на экране, полноэкранный режим с поворотом, приближение двумя пальцами до 5×, ряд кнопок Esc/Tab/стрелки/Win/Alt+Tab/Ctrl+C/V/Z/Alt+F4/F5/F11), управление касаниями: клик, правый клик удержанием, перетаскивание, прокрутка двумя пальцами, клавиатура | P5 | 🟨 | Без сторонних библиотек. Видео H.264 на ПК владельца ещё не проверено. Разрешение `screen` + подтверждение на ПК при первом показе. Только основной монитор; часть игр и защищённое видео — чёрные; без звука. Проверено тестами; на реальном ПК — ещё нет. |
| Automation | Когда: по расписанию (дни недели), по датчику (температура GPU, загрузка CPU, память — с выдержкой), при включении ПК, при входе в Windows; условие «только с … до …»; действия: профиль, программа, подсветка, блокировка, сон, выключение/перезагрузка с отсчётом, уведомление, пауза. Шаблоны «Ночь», «Перегрев», «При входе» | P6 | ✅ | Выполняется на ПК без телефона. Нужно разрешение `automation` (выдаёт администратор ПК). Проверено на реальном ПК с iPhone. Пропущенное время (ПК спал) не догоняется. |
| History | Команды с телефона, запуски автоматизаций, предупреждения и события питания — по дням | P6 | ✅ | Без содержимого (имён файлов, текста). Хранится до 2 МБ + предыдущий файл. История графиков — в «Мониторинге» (до перезапуска службы). Проверено на реальном ПК с iPhone. |
| File Transfer | Фото, видео и файлы с iPhone на ПК (в «Загрузки\\Nexus PC») и обратно; прогресс и скорость, отмена, проверка SHA-256, докачка после обрыва | P7 | ✅ | Нужно разрешение `files` (выдаёт администратор ПК). Проверено на реальном ПК с iPhone. Без подпапок. Передача идёт, пока приложение открыто (плюс ~30 с в фоне). |
| Clipboard | Текст с iPhone в буфер ПК и обратно, по нажатию | P7 | ✅ | Нужно разрешение `clipboard`. Только текст (не картинки). Проверено на реальном ПК с iPhone. |
| Multi-PC | Несколько ПК, переключение | P8 | ✖ | Не делается — решение владельца (2026-11-17). Модель данных поддерживает несколько ПК с P1. |
| Nexus AI | План → подтверждение → выполнение | P9 | ✖ | Не делается — решение владельца (2026-11-17). |
