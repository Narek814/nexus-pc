# Nexus PC — Функции и статус

Легенда: ⬜ не начато · 🟨 в работе · 🟦 заглушка/прототип · ✅ готово и проверено на реальном устройстве

Пользовательские функции пока не реализованы — все ⬜. Готова только основа: протокол и проверка команд (см. первую строку). Статус ✅ ставится только после проверки на реальном iPhone и Windows-ПК.

| Модуль | Функция | Этап | Статус | Ограничения платформы |
|--------|---------|------|--------|-----------------------|
| Core | Протокол v1: схема, разбор запросов, белый список команд, разрешения, защита от повторов, подтверждение critical | P0/P1a | 🟨 | Реализовано и покрыто тестами в `Nexus.Core`, но ещё не подключено к сети (нет Agent). |
| Power | Wake-on-LAN | P1 | ⬜ | Бесплатно (D11): WoL роутера или unicast-пакет на IP — ненадёжно после полного выключения. |
| Power | Выключение / перезагрузка / сон / блокировка | P1 | ⬜ | Блокировка — через Tray (нужен вошедший пользователь). |
| Power | Текущее состояние ПК | P1 | ⬜ | «Выключен» и «нет связи» неразличимы без Gateway. |
| Apps | Реестр приложений, запуск, группы, закрытие разрешённых | P1 | ⬜ | Запуск только в сеансе пользователя (Tray). |
| Profiles | CRUD профилей (Gaming/Developer/Creator/Night) | P1 | ⬜ | |
| Command Center | Главный экран | P2 | ⬜ | |
| Design System | Токены и компоненты | P2 | ⬜ | |
| Siri | App Intents (вкл/выкл ПК, профили, статус) | P3 | ⬜ | Фразы на русском — через AppShortcuts с локализацией. |
| Widgets | Статус, состояние, профили, быстрые действия | P3 | ⬜ | Обновление по бюджету iOS; без App Groups виджет сам опрашивает ПК. |
| Live Activities | Подключение, включение ПК, файлы, автоматизации | P3/P7 | ⬜ | Только локальные обновления из приложения (нет APNs). |
| Notifications | События ПК | P3 | ⬜ | В фоне — через ntfy или Telegram-бот (D11). |
| Monitoring | CPU/GPU/RAM/VRAM, частоты, температуры, диски, сеть, графики, история | P4 | ⬜ | Температуры CPU — через LHM (права администратора, драйвер). |
| Smart Alerts | Пороги, троттлинг | P4 | ⬜ | |
| Touchpad | Курсор, клики, прокрутка, жесты, клавиатура, медиа, громкость | P5 | ⬜ | Не работает на защищённом рабочем столе (UAC). |
| Remote Screen | WebRTC-трансляция и управление | P5 | ⬜ | Требует спайка по выбору WebRTC-стека. |
| Automation | Триггер → Условие → Действие | P6 | ⬜ | Выполняется на ПК. |
| History | Сеансы, команды, события, телеметрия, хранение | P6 | ⬜ | |
| File Transfer | Отправка/получение, прогресс, отмена, SHA-256, папки | P7 | ⬜ | Фоновые загрузки iOS — background URLSession. |
| Clipboard | Ручная отправка/получение текста | P7 | ⬜ | Только по явному действию. |
| Multi-PC | Несколько ПК, переключение | P8 | ⬜ | Модель данных — с P1. |
| Nexus AI | План → подтверждение → выполнение | P9 | ⬜ | Ollama на ПК (нужна видеокарта) + правила. |
| RGB | Цвет, яркость, эффекты, профили | P10 | ⬜ | Поддержка только проверенного оборудования (OpenRGB / Dynamic Lighting). |
| Remote infra | Установщик, обновления, инструкции | P11 | ⬜ | Без платных сервисов: установщик и инструкции. |
