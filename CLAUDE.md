# Nexus PC — инструкции для Claude Code

Проект — iPhone-приложение и Windows-агент для управления ПК по домашней сети. Сейчас идёт подготовка к публичному продукту: план в `docs/COMMERCIAL_PLAN.md`. Общие правила проекта, обязательные и для главной сессии, и для субагентов, — в `.claude/AGENT_RULES.md`.

## Субагенты (`.claude/agents/`)

| Агент | Режим | Когда вызывать |
|-------|-------|----------------|
| `code-architect` | только чтение | структура, протокол, план изменений, затрагивающих несколько компонентов |
| `security-auditor` | только чтение | аудит pairing, TLS, ключей, IPC, установщика, сторонних компонентов, аккаунтов |
| `qa-engineer` | только чтение (запускает тесты) | прогон тестов, разбор CI, регрессии, тест-планы |
| `ui-ux-designer` | пишет только `docs/design/` | экраны, навигация, дизайн-система, тексты, доступность |
| `ios-developer` | меняет `ios/**` | код Swift/SwiftUI, локализация iOS |
| `windows-developer` | меняет `windows/**` | C#: Agent, Tray, Setup, тесты, локализация Windows |
| `android-developer` | `docs/ANDROID_ROADMAP.md`; `android/**` — только после одобрения владельца | совместимость с будущим Android |
| `release-manager` | версии, workflow релиза, документы релиза | подготовка и проверка релизов (без публикации) |

## Правила оркестрации

1. Агентов-исполнителей (`ios-developer`, `windows-developer`, `android-developer`, `release-manager`, `ui-ux-designer`) **не запускать одновременно**, если они могут менять одни и те же файлы. Агентов только для чтения можно запускать параллельно.
2. Порядок изменения:
   1. `code-architect` готовит план (и `security-auditor`, если затронута безопасность);
   2. план согласуется с владельцем;
   3. исполнитель вносит изменение;
   4. `qa-engineer` проверяет.
3. Предложения агентов анализа об изменении кода — это предложения. Решение принимает главная сессия в рамках требований владельца.
4. Протокол, схемы, Bundle ID, подпись, зависимости, платные сервисы, публикация, необратимые git-операции — только с явного разрешения владельца (`.claude/AGENT_RULES.md`, раздел 2).
5. Apple Developer Program и публикация в App Store — последний этап проекта.
