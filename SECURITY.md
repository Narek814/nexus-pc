# Nexus PC — Безопасность

Статус: **v0.1, этап P0** (модель угроз и обязательные требования; реализации пока нет).

## 1. Что защищаем
- Управление ПК (выключение, запуск программ, ввод с клавиатуры/мыши).
- Изображение экрана, содержимое буфера обмена, файлы.
- Ключи сопряжения и токены сессий.
- Историю действий и телеметрию (приватные данные).

## 2. Модель угроз
| Угроза | Пример | Меры |
|--------|--------|------|
| Посторонний в той же Wi-Fi сети | Сканирует порты, пытается отправить команду | Только TLS; без сопряжённого ключа агент отвечает лишь на `hello`/`pair`; rate limit; сопряжение только при подтверждении на ПК. |
| MITM в LAN | Подмена агента | Pinning сертификата агента (отпечаток из QR при сопряжении). |
| Утерянный/украденный iPhone | Доступ к ПК | Ключ в Secure Enclave, доступ по Face ID/коду для `critical`; отзыв устройства на ПК одним кликом. |
| Скомпрометированный Relay | Чтение/подмена трафика | E2E-шифрование поверх relay (Noise/TLS внутри туннеля); relay видит только метаданные. |
| Prompt injection в AI | «Удали System32» | AI выдаёт только шаги из каталога команд; детерминированный валидатор; подтверждение пользователем. |
| Подмена Tray локальным вредоносом | Процесс подключается к pipe | ACL на pipe + проверка пути и подписи процесса-клиента. |
| Path traversal в файлах | `..\..\Windows` | Канонизация пути, запрет reparse points/символических ссылок, только разрешённые корни. |
| Утечка паролей через буфер | Синхронизация скопированного пароля | Только ручная отправка; пропуск форматов, помеченных менеджерами паролей (`ExcludeClipboardContentFromMonitorProcessing`, `CanIncludeInClipboardHistory=0`). |

## 3. Обязательные требования
1. **Шифрование:** TLS 1.2+ (предпочтительно 1.3) для WSS/HTTPS; DTLS-SRTP для WebRTC. Нет нешифрованных режимов, даже «для отладки» в релизной сборке.
2. **Сопряжение:** QR на экране ПК содержит `pcId`, адрес, отпечаток сертификата, одноразовый код (TTL 2 мин). Сопряжение подтверждается кнопкой на ПК.
3. **Аутентификация:** iPhone — ключ P-256 в Secure Enclave; агент — ключ TLS-сертификата в хранилище компьютера Windows (CNG, неэкспортируемый). Вход: challenge-response по каждому соединению (docs/API.md «Вход»); подпись привязана к nonce, `pcId`, `deviceId` и отпечатку TLS-сертификата. Вход живёт ≤ 1 ч на соединении; отдельных токенов нет.
4. **Авторизация:** разрешения на устройство × на ПК (`power`, `apps`, `monitoring`, `input`, `screen`, `files`, `clipboard`, `rgb`, `automation`, `ai`). По умолчанию после сопряжения выдаются только `monitoring`, `apps`, `power`, `rgb` (с P10: подсветка безвредна) — остальное включается явно. Устройствам, сопряжённым раньше, `rgb` добавляет администратор: `Nexus.Agent.exe devices permissions <deviceId> power,apps,monitoring,rgb`.
5. **Нет произвольного выполнения:** нет команд shell/PowerShell/«запустить путь». Приложения — только из реестра, добавленного/подтверждённого на ПК. Закрытие — только приложений из того же реестра.
6. **Критические действия:** shutdown/restart — подтверждение на iPhone (+ Face ID по настройке). Управление вводом (P5): разрешение `input` выдаёт только администратор ПК, при сопряжении его нет; когда телефон начинает управлять (после 2 мин тишины), трей показывает уведомление на ПК; «Стоп» — пункт меню трея «Запретить управление мышью и клавиатурой с телефона». Удалённый экран (позже) — подтверждение на ПК и видимый индикатор трансляции.
7. **Сеть:** агент принимает подключения только на локальные адреса loopback, частных сетей (10/8, 172.16/12, 192.168/16) и Tailscale (100.64/10). Он слушает все IPv4-адреса, но каждое подключение проверяется по адресу, на который оно пришло, **до TLS**; остальные сразу обрываются. Второй уровень — правило брандмауэра «только частная сеть». Раньше агент привязывался к адресам, найденным при старте, и после перезагрузки не видел Wi-Fi, подключившийся позже (найдено на реальном ПК). Никаких UPnP и пробросов портов. Удалённо — VPN (Tailscale).
8. **Защита API:** валидация каждого сообщения по JSON Schema, лимиты размеров, rate limiting, защита от повторов (`id` + `ts`, окно ±5 мин).
9. **Секреты на iPhone:** только Keychain (`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`), общий доступ app/widget через Keychain access group. Никаких ключей AI в бинарнике приложения.
10. **Журнал аудита:** каждая команда (кто, когда, что, результат) пишется в историю на ПК; хранение настраивается.
11. **Внешние пуши (ntfy, D11, реализовано в P4b):** выключены по умолчанию, включаются владельцем в приложении. В тексте — имя ПК, событие и числа (температура, %, ГБ); без путей, имён программ, содержимого буфера, IP-адресов. Канал ntfy — случайный (128 бит) `nexuspc-…`, хранится в `alerts.json` в защищённой папке данных, показывается только устройствам с разрешением `monitoring`; можно сменить (`regenerateTopic`) или указать свой сервер ntfy (только https).
12. **Флаг подтверждения `confirmed`** — защита от случайных действий (UX), а не механизм безопасности: его ставит клиент после подтверждения пользователем. Безопасность обеспечивают ключи и разрешения (п. 3–4). Для удалённого экрана и ввода подтверждение дополнительно требуется на самом ПК.
13. **Обновления:** подписанные сборки Agent/Tray; служба работает с минимально необходимыми правами (решение об учётной записи — P1, см. ниже).

## 4. Решения P1b и открытые вопросы
- **Учётная запись службы — `LocalSystem` (временно).** Нужен доступ к хранилищу сертификатов компьютера и `SeShutdownPrivilege`. Компенсация: строгая проверка всех входящих данных, белый список команд, нет запуска процессов из службы. Переход на виртуальную учётную запись `NT SERVICE\NexusPCAgent` с выдачей только `SeShutdownPrivilege` и ограничение привилегий через `sc.exe privs` — после ручной проверки на реальном ПК (нельзя проверить в облаке).
- **Канал администратора** — именованный канал `NexusPC.Admin`: доступ SYSTEM и повышенным администраторам, сетевой доступ явно запрещён (`NETWORK` deny), `FirstPipeInstance` против перехвата имени. Через него — открытие сопряжения, подтверждение, отзыв устройств, разрешения. Открыто: клиент пока не проверяет, что сервер канала — именно служба (подмена канала до старта службы даёт злоумышленнику только поддельные запросы на подтверждение, но не ключи).
- **Выключение из службы** требует `SHUTDOWN_FORCE_OTHERS` (сеанс пользователя для SYSTEM — «чужой»). Защита несохранённой работы до P1c — обязательный отсчёт ≥ 30 с для запросов без `force`, с уведомлением Windows и возможностью отмены.
- **Канал службы и трея** `NexusPC.Session`: доступ — интерактивные пользователи и администраторы, сеть запрещена. Проверка **в обе стороны**: служба (SYSTEM) принимает только процесс `…\NexusPC\Tray\Nexus.Tray.exe` из Program Files (запись только у администраторов); трей (обычный пользователь не может открыть процесс SYSTEM) сверяет процесс на другом конце канала с процессом службы `NexusPCAgent` по данным диспетчера служб — установить или изменить службу может только администратор. Трей может только открыть сопряжение, подтвердить его, посмотреть и **отозвать** устройства; выдавать разрешения — только администратор через CLI (белый список `SessionOps.AllowedFromTray`).
- **Список программ** хранится в профиле пользователя (`%LOCALAPPDATA%\NexusPC`) и редактируется только на ПК. Телефон видит только id и названия, **пути не покидают ПК**. Программы запускаются от имени пользователя, а не SYSTEM. Трей отказывается работать с правами администратора, чтобы программы с телефона не получали повышенных прав. Закрытие программ — только мягкое (как кнопка ×), без принудительного завершения процессов.
- **Надёжность каналов:** ошибки создания экземпляров каналов пишутся в журнал и повторяются, а не останавливают службу (найдено CI: исключение фоновой задачи останавливало весь хост).
- **Ссылки `nexuspc://`** может открыть любой сайт или приложение. Поэтому: ссылка сопряжения сначала спрашивает подтверждение; `action/shutdown` только открывает диалог подтверждения; `action/lock` и `action/profile/<id>` выполняются сразу (не опасны и запускают лишь программы из списка, составленного на ПК).
- **Siri:** разрушительные действия и запуск программ требуют разблокированного iPhone (`authenticationPolicy = .requiresAuthentication`); выключение и перезагрузка голосом — только после подтверждения в Siri и с отсчётом (по умолчанию 5 минут), который можно отменить. Раньше было 1 минута без подтверждения — на реальном ПК этого не хватило, чтобы отменить.
- **Tailscale:** отдельное правило брандмауэра разрешает порт 47800 только с адресов 100.64.0.0/10 (сеть Tailscale), служба дополнительно проверяет адрес подключения. Порты в роутере не открываются. `pc.status` отдаёт адреса и MAC только авторизованным устройствам.
- **Файлы данных** — `C:\ProgramData\NexusPC`, наследование отключено, доступ только SYSTEM и Administrators. Журнал аудита `audit.log` (JSON-строки, без содержимого запросов, ротация 5 МБ).
- **DevClient** хранит закрытый ключ **без шифрования** — только для проверки, не для повседневного использования.
- Формат E2E поверх Relay (Noise IK vs вложенный TLS) — только если когда-либо понадобится Relay (D11).

## 5. Сообщение об уязвимостях
Пока проект приватный — сообщать владельцу репозитория напрямую.

## Подсветка (P10)

SDK-сервер OpenRGB не имеет авторизации. Агент подключается к нему только по `127.0.0.1`; порт 6742 в брандмауэре не открывать. Телефон не может передать OpenRGB произвольные данные: только цвет `#RRGGBB`, яркость 0–100 и имя режима, который устройство само сообщило.

## Тачпад и клавиатура (P5)

Разрешение `input` по сути даёт полный контроль над рабочим столом вошедшего пользователя (можно напечатать что угодно в любом окне), поэтому оно выключено по умолчанию и включается только командой администратора на ПК. Ограничения: трей работает с обычными правами, поэтому окна администратора, запрос UAC и экран блокировки телефону недоступны (Windows это запрещает). Клавиши — только из фиксированного списка; сочетания отпускаются в том же вызове; кнопка мыши, зажатая для перетаскивания, отпускается сама через 5 с без команд. Набранный текст не пишется в журнал.

## Файлы и буфер обмена (P7)

Разрешения `files` и `clipboard` не выдаются при сопряжении — их включает администратор ПК. Телефон не может прочитать произвольный файл: доступна только папка `Загрузки\Nexus PC`, без подпапок и ссылок, по точному имени. Присланный файл проверяется по SHA-256, получает безопасное имя, не перезаписывает существующие и помечается Mark of the Web; он никогда не запускается автоматически. Буфер обмена — только по явному действию на телефоне, с уведомлением на ПК; автоматической синхронизации нет (требование ТЗ). Повышенный лимит сообщения (1 МиБ) действует только после входа.

## Автоматизации (P6)

Разрешение `automation` не выдаётся при сопряжении. Повышения прав нет: правило может делать только то, что создавшее его устройство может делать само, и это проверяется и при сохранении, и перед каждым шагом (отзыв устройства останавливает его правила). Действия — только из фиксированного списка; выключение — не раньше чем через 60 секунд с отсчётом Windows и только после подтверждения при сохранении. Файл правил лежит в папке данных службы (доступ только у SYSTEM и администраторов).

## Установщик (P11)

`NexusPC-Setup.exe` запрашивает права администратора (манифест). Все системные программы (`sc.exe`, `netsh.exe`, `powershell.exe`) вызываются по абсолютному пути из System32 — подложенный рядом с установщиком `sc.exe` не запустится с правами администратора. Встроенный архив проверяется до записи на диск: только `Agent/`, `Tray/` и `version.txt`, без `..` и дисков в путях. Правило брандмауэра — только для `Nexus.Agent.exe`, TCP 47800, профиль «Частная». Сеть делается частной только после явного «да» для каждой сети. Трей запускается через Проводник с обычными правами, не от администратора. Установщик не подписан (подпись платная, D11) — проверяйте, что скачиваете его со страницы сборки своего репозитория.

Окно «Устройства и разрешения» в трее: отключить устройство может человек за ПК без прав администратора (только уменьшает доступ); выдача разрешений запускает `Nexus.Agent.exe devices permissions` из Program Files с запросом прав администратора (UAC) — в командной строке только GUID устройства и имена разрешений из фиксированного списка.
